# Data Visualization for AI/ML

This repository contains beginner-friendly Python programs for data visualization using Matplotlib, Seaborn, and Pandas.

## Topics Covered

- Line Plot
- Bar Chart
- Pie Chart
- Histogram
- Scatter Plot
- Multiple Plots
- Seaborn Scatter Plot
- Correlation Heatmap
- Correlation Analysis
- Student Marks Visualization

## Technologies Used

- Python
- Matplotlib
- Seaborn
- Pandas

## Installation

Install the required libraries:

```bash
pip install matplotlib seaborn pandas
```

## Purpose

The purpose of this repository is to learn how to visualize and analyze data before applying Machine Learning algorithms.
